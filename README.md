- 🤖 Currently shipping a **14-tool AI Agent** powered by Anthropic Claude into a production SaaS
- 🇦🇺 Based in **Leeton, NSW, Australia** — building Australian-first software with AUD-native billing
- 🛠️ Comfortable owning a system end-to-end: frontend, backend, AI integration, DevOps, SEO, billing
- 💬 Open to **Senior / Lead Full-Stack** roles (remote-friendly across AU) and **AI-integration contracts**
